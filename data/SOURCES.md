# Data sources

## Synthetic data (used for tests and the demo)

All demo and test data is generated by `nxcat.synthetic`. Instrument names are
real ISIS and ESS instruments, but every value (runs, samples, temperatures,
times, counts) is random and fake.

```bash
cd backend
uv run nxcat-generate --out ../data/generated -n 200 --seed 42
uv run nxcat-generate --out ../data/generated -n 0 --with-broken   # bad files for testing
```

Generated files go to `data/generated/`, which is git-ignored.

## Public files

None yet. Before adding a public NeXus file, check its licence and record here:
the source URL, the licence and the date checked.
